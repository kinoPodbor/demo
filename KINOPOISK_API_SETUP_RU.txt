КИНОПОДБОР — ПОДКЛЮЧЕНИЕ KINOPOISK.DEV (ЗАЩИЩЁННЫЙ СПОСОБ)

ВАЖНО О ТОКЕНЕ
Не вставляй секретный токен в app.js, index.html или в публичный репозиторий.
Токен, который уже отправлялся в чат, лучше перевыпустить через официальный для сервиса Telegram-бот/личный кабинет.
Новый токен будет введён непосредственно в Cloudflare как Secret и не попадёт в исходники сайта.

АВТОМАТИЧЕСКАЯ НАСТРОЙКА
1. Создай бесплатный аккаунт Cloudflare: https://dash.cloudflare.com/sign-up
2. Установи Node.js LTS: https://nodejs.org/
3. Открой папку cloudflare-worker.
4. Дважды нажми SETUP_AND_DEPLOY.bat.
5. При первом запуске откроется браузер — войди в Cloudflare и разреши подключение.
6. В окне командной строки появится запрос токена. Вставь новый Kinopoisk.dev токен и нажми Enter.
7. Дождись публикации. Скопируй адрес вида https://имя-воркера.твой-аккаунт.workers.dev.

ПОДКЛЮЧЕНИЕ К САЙТУ
1. Открой КиноПодбор.
2. Нажми Настройки.
3. Вставь скопированный адрес в поле «Адрес Cloudflare Worker».
4. Сохрани настройки.

ПРОВЕРКА
Открой в браузере адрес Worker с путём:
/genre/movie/list?language=ru-RU
Должен появиться JSON со списком жанров.

ПРИМЕЧАНИЯ
- Kinopoisk.dev — сторонний сервис, не официальный API Яндекса/Кинопоиска.
- Cloudflare Worker передаёт запросы к Kinopoisk.dev; секрет хранится в настройках Cloudflare.
- Бесплатные лимиты Cloudflare и Kinopoisk.dev могут меняться.
- Избранное, просмотренное и отзывы пока сохраняются локально в браузере; облачная синхронизация не подключена.


ВАЖНО О ТОКЕНЕ: в этом персональном архиве токен уже прописан в SETUP_AND_DEPLOY.bat. Не публикуй архив и не отправляй его другим людям. Установщик передаёт токен в Cloudflare как Secret; токен не добавляется в JavaScript сайта. Поскольку токен уже раскрывался в переписке, после проверки рекомендуется выпустить новый и заменить его.
