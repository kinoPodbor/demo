КИНОПОДБОР — КАК ОТКРЫТЬ НА IPHONE

ВАЖНО
START.bat запускает предварительный просмотр на компьютере. Он НЕ публикует сайт в интернете: для доступа с iPhone вне компьютера проект нужно бесплатно разместить на статическом хостинге. Mac и собственный сервер не нужны.

САМЫЙ ПРОСТОЙ ПУТЬ — GITHUB PAGES
1. Создай бесплатный аккаунт на https://github.com/ (если его ещё нет).
2. Создай новый Public repository с названием kinopodbor.
3. На странице репозитория нажми Add file → Upload files.
4. Загрузи ТОЛЬКО файлы сайта: index.html, styles.css, app.js, manifest.webmanifest, sw.js и icon.svg. НЕ загружай папку cloudflare-worker, SETUP_AND_DEPLOY.bat, README и любые файлы с токеном — репозиторий Public, секрет нельзя публиковать.
5. Нажми Commit changes.
6. Открой Settings → Pages.
7. В разделе Build and deployment выбери Deploy from a branch, Branch: main, folder: /(root), нажми Save.
8. Подожди публикации. Адрес будет вида https://ТВОЙ-ЛОГИН.github.io/kinopodbor/.
9. Открой этот адрес в Safari на iPhone → кнопка «Поделиться» → «На экран Домой» → «Добавить».

КАТАЛОГ ФИЛЬМОВ
Для актуального каталога и игры нужен опубликованный Cloudflare Worker. Сначала на своём компьютере запусти cloudflare-worker\SETUP_AND_DEPLOY.bat, чтобы опубликовать Worker. Затем в приложении в ⚙ вставь адрес Worker, а не секретный токен. Папку cloudflare-worker и установщик с токеном не загружай в Public GitHub-репозиторий. Если обновил игру, повторно запусти установщик.

ПРИМЕЧАНИЯ И ОГРАНИЧЕНИЯ
- Данные и изображения предоставляются сторонним сервисом Kinopoisk.dev / ПоискКино; соблюдай его условия и лимиты API. КиноПодбор не аффилирован с Кинопоиском.
- Избранное, просмотренное и пользовательские оценки сохраняются в браузере конкретного устройства. Между iPhone и компьютером они автоматически не синхронизируются.
- Регистрация, облачная синхронизация и серверные отзывы в этой версии не реализованы.
- Не публикуй свой API-токен в открытом репозитории и не отправляй его другим людям. В этой простой клиентской версии токен хранится в локальном хранилище браузера; для публичного коммерческого сервиса нужен отдельный backend/proxy.
