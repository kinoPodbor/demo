КИНОПОДБОР — WEB/PWA ВЕРСИЯ

ЗАПУСК НА WINDOWS
1. Распакуй архив в обычную папку.
2. Дважды нажми START.bat.
3. Откроется сайт в браузере. Нужен установленный Python 3 (подойдёт и Python 3.14); дополнительные библиотеки не устанавливаются.

ЧТО УЖЕ РАБОТАЕТ
- Адаптивный интерфейс для компьютера и iPhone.
- Демонстрационный каталог, поиск, жанры, годы и сортировка.
- Подключение Kinopoisk.dev через защищённый Cloudflare Worker (секретный токен не хранится в браузере).
- Карточка фильма, описание, ссылка на поиск в Кинопоиске.
- «Удиви меня», избранное, просмотренные и локальные оценки/отзывы.
- Выбор языка интерфейса: русский и английский.
- Игровой режим «Угадай фильм по кадру»: фильмы/мультфильмы, 5–20 раундов, 3 уровня сложности, 5 сердец на раунд и 4 подсказки за сердце.
- Локальная таблица рекордов с количеством правильных ответов, очками и временем.
- Установка как PWA на главный экран iPhone после публикации на HTTPS-хостинге.

ЧЕГО ПОКА НЕТ
- Регистрации и входа.
- Облачной базы и синхронизации между устройствами. Таблица рекордов пока хранится в браузере конкретного устройства; общий онлайн-рейтинг потребует отдельной базы и аккаунтов.
- Серверного хранения отзывов.
Это честная рабочая стартовая версия без собственного backend. Инструкция публикации — PUBLISH_TO_IPHONE_RU.txt.

Подключение Kinopoisk.dev: смотри KINOPOISK_API_SETUP_RU.txt и папку cloudflare-worker.

ВАЖНО: не вставляй секретный Kinopoisk.dev токен в файлы сайта.
Для безопасного ввода и публикации Worker запусти cloudflare-worker\\SETUP_AND_DEPLOY.bat.
Подробная инструкция: KINOPOISK_API_SETUP_RU.txt.


ВАЖНО О ТОКЕНЕ: в этом персональном архиве токен уже прописан в SETUP_AND_DEPLOY.bat. Не публикуй архив и не отправляй его другим людям. Установщик передаёт токен в Cloudflare как Secret; токен не добавляется в JavaScript сайта. Поскольку токен уже раскрывался в переписке, после проверки рекомендуется выпустить новый и заменить его.

ОБНОВЛЕНИЕ ИГРЫ: чтобы заработал режим «Угадай фильм по кадру», запусти cloudflare-worker\SETUP_AND_DEPLOY.bat ещё раз — он обновит Worker и подключит получение скриншотов. После публикации используй прежний адрес workers.dev в настройках сайта.
